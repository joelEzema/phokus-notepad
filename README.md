# phokus-notepad
My biggest project yet... or maybe my first actual project

## What *is* Phokus tho?
Well, Phokus is a small project I decided to start. The whole idea was to make a notepad that actively penalized the user for getting distracted. It slowly evolved from that to a text editor that not only roasts you for having the attention span of the average Gen Alpha kid, but one that also praises you for staying focused on the actual goal.
